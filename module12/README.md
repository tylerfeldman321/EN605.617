# Module 12 Assignment - Audio Panning
Tyler Feldman

## Prequisites
- Ubuntu 22.04
- OpenCL installed
- Install libsndfile:
```bash
sudo apt-get update
sudo apt-get install libsndfile1-dev
```

## Building and Running
```bash
make
./audio-panning.exe M1F1-uint8-AFsp.wav 
```
